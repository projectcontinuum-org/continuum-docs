Repositories

Project Continuum is split across several focused repositories under the projectcontinuum-org GitHub organization — not a monorepo. Each one can be built and released independently.

Multi-repoIndependently releasedApache 2.0
RepositoryDescription
continuum-platform-coreCore backend — API server, Temporal orchestration, message bridge, credentials server, cluster manager, cloud gateway
continuum-workbenchBrowser IDE — Eclipse Theia + React Flow workflow editor
continuum-feature-baseBase analytics nodes — data transforms, REST, scripting, anomaly detection
continuum-feature-aiAI/ML nodes — LLM fine-tuning with Unsloth + LoRA
continuum-feature-cheminformaticsCheminformatics nodes — RDKit-powered molecular processing
continuum-feature-knimeKNIME-compatible workflow executors
continuum-feature-templateTemplate — scaffold your own custom feature worker
continuum-chartsHelm charts for deploying Continuum on Kubernetes
continuum-local-setupDocker Compose setup for running the entire platform locally
continuum-websiteMarketing site (projectcontinuum.org)
continuum-docsThis documentation site

Feature workers are independent​

Feature workers (continuum-feature-*) are not part of continuum-platform-core — each lives in its own repo with its own build and release pipeline, and can be deployed as an independent worker service into the same namespace as the core platform. This is intentional: new capabilities ship as new workers, not as changes to existing ones. See Node Model & Feature Registration for how a worker's nodes get discovered by the platform at runtime.
