# KNIME Nodes

[`continuum-feature-knime`](https://github.com/projectcontinuum-org/continuum-feature-knime) provides Continuum workflow executors for KNIME workflows (`.knwf` files), bridging KNIME's compatibility layer (`continuum-knime-base` in `continuum-platform-core`) with Continuum's execution model.

This worker doesn't yet have a published node reference — check the [repository](https://github.com/projectcontinuum-org/continuum-feature-knime) directly for current capabilities.
