Why Continuum

Everything a data pipeline needs, nothing to install

Design in the browser, run on durable infrastructure, and extend the platform without touching its core.

Browser-native canvas

A full IDE built on Eclipse Theia and React Flow. Drag, drop and connect nodes with nothing to install.

Learn more →

Crash-proof execution

Every run is a durable Temporal workflow. A crashed worker, a restarted pod or a dropped connection doesn't lose progress.

Learn more →

Live execution updates

Events flow from Kafka to the browser over MQTT and WebSockets, so each node lights up as it runs. No polling.

Learn more →

Columnar data

Nodes exchange Snappy-compressed Apache Parquet tables stored in MinIO, not JSON blobs. Fast and query-ready.

Learn more →

Extensible by design

Add capabilities by deploying a new feature worker. Existing services stay untouched: zero downtime, zero coupling.

Learn more →

Kubernetes-ready

Helm charts for the infrastructure, the platform and each worker take you from a laptop to a production cluster.

How it works

From canvas to results in four steps

Each node is a Temporal activity dispatched to the worker that owns it, with live progress streamed back to you.

  1. 1

    Design

    Drag nodes onto the canvas in the Workbench, configure them and hit Execute.

  2. 2

    Orchestrate

    The API server starts a Temporal workflow that walks the graph and runs independent nodes in parallel.

  3. 3

    Execute

    Each node runs on the feature worker that registered it, reading and writing Parquet in MinIO.

  4. 4

    Watch

    Progress events travel through Kafka and MQTT and light up every node live in your browser.

Quick start

The whole platform, one command away

No builds and no cloning five repositories. Docker Compose starts the infrastructure, the platform backend, the Workbench and the feature workers, already wired together with example workflows.

  • Temporal, Kafka, MinIO and PostgreSQL included
  • Workbench at localhost:3002 with example workflows
  • Base, cheminformatics and AI workers ready to use
Local setup guide
bash
$ git clone https://github.com/projectcontinuum-org/continuum-local-setup.git
$ cd continuum-local-setup/docker
$ docker compose up -d
✔ Continuum is up: open http://127.0.0.1:3002
